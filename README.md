# CARGA · gimnasio (proyecto de muestra)

Web de un gimnasio ficticio en Los Palos Grandes, Caracas, hecha para el portafolio de Josías Palmares.

- Horario de clases por día y por tipo, que marca la clase en curso y la próxima, con "Reservar cupo" por WhatsApp.
- "¿Qué plan te conviene?": tres preguntas y recomienda un plan con su precio en $ y Bs (tasa BCV de ve.dolarapi.com).
- Áreas del gimnasio, planes, entrenadores, preguntas frecuentes y ubicación con mapa.

Hecho con React, TypeScript, Tailwind CSS 4 y Magic UI (BlurFade). Fotos de Pexels; mapa de OpenStreetMap.

```bash
npm install
npm run dev
npm run build
```
